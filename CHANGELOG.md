# Changelog

Release tags are `vMAJOR.MINOR.PATCH`; the protocol version a component declares is `MAJOR.MINOR` (README, *Versioning*).

## v1.0.0-rc.2

Rulings from the first SDK, suite and be-ops lanes (stage B, wave 1), applied before the pilot components. Requires brickKit ≥ v1.4.0.

- **Reasons** of domain `be`: 36 (was 33). New `REQUEST_INVALID` (`INVALID_ARGUMENT`, 400: the request does not decode or match its schema), `DEPENDENCY_UNAVAILABLE` (`UNAVAILABLE`, 503, `metadata.dependency` = `db`, `bus`, `blob` or a component or family ID; SQLSTATE class `08`, `57P01`–`57P03`), `REQUEST_CANCELLED` (`CANCELLED`, 499: every error the runtime answers now has a reason). The access-log line's level follows the response's code (P4.6).
- **Route decision order**: verify the token (401) → no bundle yet → `503` for every non-Public route, Authenticated included → stale token or revoked grant (`TOKEN_STALE`) → delegation capabilities along the `act` chain, `impersonation` included (`UNSUPPORTED_DELEGATION`) → Authenticated → key. A `413` may come before the guard.
- **Configuration**: an empty value counts as not set for every type; booleans `true`, `false`, `1`, `0`; `one_of` = at least one; `EVENTS_MAX_DELIVER` / `EVENTS_BACKOFF` have no catalogue default (the subscription's own value applies); `PG_POOL_MIN_IDLE` removed; new `DEPLOY_ENV`; `DEFAULT_LOCALE` falls back to `en` outside `zh` / `en`; no `COMPONENT_ID` exits 64; profile trigger keys (`db`: `PG_SCHEMA` or `PG_HOST`; `blob`: `S3_BUCKET` or `S3_URL`); catalogue field `shell: process | member`.
- **OpenAPI markers**: every operation declares `x-be-permission`; a missing one fails closed unless the operation is `x-be-internal: true` (provider plane, operations endpoints; never routed, exempt from edge coverage). The operations endpoints in `openapi/ops.yaml` carry it; the widget's OpenAPI carries the be-ops–generated resource-contract region.
- **Database and migrations**: `PG_SCHEMA` ≤ 40 characters; session-level `application_name` `<component ID>@<version>` and one session always open per member (shell: a presence session); `-- be:contract after=<version>` stops the migration with exit 1 while a session of that version or older is connected; capability probe by `server_version_num` only; blocker logging without query text unless visible; `be_tx_retries_total{sqlstate}`; the authorization projection only in schemas that declare `resources`.
- **Events**: payloads above 64 KiB are refused at publish; the last allowed delivery naks and the message is dead-lettered at its next receipt; subscription aggregate type with `ce-aggregatetype` fallback; `x-signal: true` for pokes in the events contract; outbox column `tracestate`; partitions named `<parent>_<ISO week-year>w<WW>` / `m<MM>` / `<YYYY>` (P16.10); the PostgreSQL queue adapter uses the component's `PG_USER`, partitions through `SECURITY DEFINER` functions owned by `be_bus_owner`, and a DEFAULT partition; a bus scheme without an adapter fails the start.
- **Observability**: `service.namespace` = the domain, `deployment.environment.name` = `DEPLOY_ENV`; an unsampled `traceparent` is propagated, not recorded; log lines ≤ 2048 bytes including the newline, with the envelope fields listed; the access log covers the user plane and the resource contract only.
- **Retention defaults**: queue rows `done` 7 days, job slots 30 days (with outbox 14 days, cursor and idempotency 30 days).
- **System plane**: a user-facing rpc answers `TOKEN_INVALID`; refusals by identity or batch limit are traced and counted (interceptor order changed); ≤ 50 ms left means not sent; `map` fields are not batches.
- **Self-description and release**: `/_be/info` `profiles` must equal the selected set; `release: {checks: [[make, conformance]]}` (P20.5); `compconf-record-scan` only for components without that check; cases may carry `applies_when` (CP-ERR-02, CP-ERR-03), reports may say `not_applicable`; fixtures gain `config` and `paired_with`. Traefik ≥ 3.6 on Docker Engine 29.
  - Requirements changed: P1.2, P1.5, P2.3, P2.8, P3.6, P3.10, P4.1, P4.6, P5.4, P5.5, P5.6, P6.2, P7.3, P7.4, P7.7, P7.10, P10.1, P10.2, P10.4, P10.5, P10.7, P11.1, P11.3, P11.4, P12.2, P12.6, P12.7, P12.10, P12.12, P12.16, P14.7, P18.1, P18.2, P18.4, P19.3, P20.4. Added: P3.16, P16.10, P20.5.
  - Vectors (981 in all): `errors` (three reasons, connection-loss SQLSTATEs, `REQUEST_CANCELLED`, op `access_log_level`), `config` (`empty-string-is-value` replaced by `empty-string-is-absent`, plus `empty-string-required`, `empty-string-optional`), `envelope` (`tracestate`, `PAYLOAD_TOO_LARGE`).
  - Schemas: `errors-be`, `config-keys` (`shell`, `DEPLOY_ENV`, retired `PG_POOL_MIN_IDLE`), `events-contract` (`x-signal`), `conformance-cases` (`applies_when`), `compconf-report` (`not_applicable`), `fixtures` (`config`, `paired_with`). DDL: outbox `tracestate`, `be_bus` owner role, DEFAULT partition and partition functions.

## v1.0.0-rc.1

First release candidate of protocol 1.0. Not frozen: the pilot components may still change it before `v1.0.0`.

- Specification P1–P20 (`spec/`), English with Chinese mirrors; requirement IDs `P<chapter>.<n>` and case IDs `CP-<GROUP>-<nn>` fixed from here on.
- Schemas (`schemas/`): configuration key catalogue, the `be` reason catalogue, problem body, event envelope, event contract file, access-token claims, `lifecycle.yaml` v1, `DATA_LIFECYCLE`, `JOBS_OVERRIDES`, the protocol keys of `assembly.yaml`, `/_be/info`, `conformance/fixtures.yaml`, the conformance case catalogue and the suite report.
- Reference DDL (`ddl/`) of every `besdk_*` table and the runtime's `SECURITY DEFINER` functions, checked on PostgreSQL 14 and 16; reference DDL of the PostgreSQL queue bus adapter (`be_bus`).
- `proto/be/v1/limits.proto` (`max_items`), `proto/be/lifecycle/v1/lifecycle.proto`; OpenAPI fragments for the operations endpoints, `_authz` / `_shares` and `_lifecycle`.
- Semantic vectors (`vectors/`) and the fixture component `conformance/widget` (`fixtures/widget/`).
- Reconciled before tagging (phase A): slot-family addresses and the derived gRPC target, family keys (`IAM_URL`, `BOOTSTRAP_ADMIN_LOGIN`, P2.10, P2.11); 33 reasons of domain `be` (`RATE_LIMITED`, `UPSTREAM_*`, `NETWORK_IN_TX`, `NESTED_TX`, `DB_TOO_MANY_CONNECTIONS`); subject segments and injective durable names (`.` → `__`); runtime-side redelivery and dead-lettering, create-if-absent durables (CP-EVS-08); `@every` schedules; normative redaction with `authorization`, `cookie`, `set_cookie`, `api_key`; `besdk_number_allocations`; thaw through `SECURITY DEFINER` functions; the `/* be:<schema> */` statement prefix; calendar degraded mode and embedded tz data in `/_be/info`; fixture fields for every fact the suite needs; `make check`. Vector case IDs `envelope.cursor.last-delivery` and `envelope.cursor.conformance-last` became `last-allowed-failure` and `conformance-last-allowed` (their meaning changed; nothing was released under the old IDs).
- Adopted brickKit v1.2–v1.3.1 before tagging (requires brickKit ≥ v1.3.1). **Family addresses** are explicit keys filled by `$endpoint:` in `config/vars.yaml`: `AUTHZ_URL`, new `AUTHZ_GRPC_URL`, `IAM_URL` (now required by `auth`), new `IAM_GRPC_URL`; the derived gRPC target (port + 1000) is gone, `IAM_JWKS_URL` is retired (`{IAM_URL}/.well-known/jwks.json`). **Secrets are files**: every `secret: true` key is `mount: file` and named `…_FILE` (`PG_PASSWORD_FILE`, `PG_OWNER_PASSWORD_FILE`, `S3_ACCESS_KEY_ID_FILE`, `S3_SECRET_ACCESS_KEY_FILE`; the old names retired), re-read within 30 s, one trailing newline removed; the runtime `@file:` form is gone; metric `be_secret_reload_failures_total`. **Readiness** `/readyz` is MUST, latched, declared as `readinessCheck`. **Stop grace**: `deployment.stopGracePeriodSeconds` (30) declared, `SHUTDOWN_GRACE` default 25 s, a shell at least its members'. **Ports** declare `protocol` (`http`, `grpc`) and listen on IPv4 and IPv6. **Events** are declared in `component.yaml` `events`, generated by be-ops. **Jobs**: optional `job run <name>` on the same lease and slot tables (`/_be/info` `capabilities: [job_run]`), exit code 64 for usage errors. `PG_MIGRATION_HOST` / `PG_MIGRATION_PORT` fall back to `PG_HOST` / `PG_PORT`; be-ops generates the protocol block of `configSchema` (gate `protocol-config-scan`); edge routes are segment-bounded; shell members may be exposed.
  - Requirements changed: P1.1, P1.4 (SHOULD → MUST), P1.6, P2.5, P2.6, P2.7, P2.8, P2.9, P2.10, P5.4, P6.10, P7.6, P10.12, P11.1, P14.5, P17.1, P19.3. Added: P1.11, P1.12, P1.13, P2.12, P7.14, P12.16, P14.8, P19.9, P19.10.
  - Cases: CP-CORE-05 becomes MUST; added CP-CORE-12, CP-CORE-13, CP-CORE-14, CP-DB-06, CP-EVP-06, CP-EVS-09, CP-JOBS-06, CP-SHELL-11. Profiles `events-pub` and `events-sub` are selected from `component.yaml` `events`.
  - Schemas: `config-keys` (`mount`, `secrets`, `applies_when` for the gRPC family keys, retired names), `info` (`capabilities`), `fixtures` (events and jobs notes). Vectors `config`: `family_url` replaced by `family_address`; new operations `secret_text`, `key_declaration`; `$endpoint:` value forms (196 cases, 946 in all). Fixtures: `readinessCheck`, `stopGracePeriodSeconds`, port `protocol`, `events`, `mount: file` secrets (`brickkit lint` v1.3.1 clean); four new broken variants.
