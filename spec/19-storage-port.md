# 19 存储端口

依据：装配项目协议 12（附件与对象存储：属主与凭据、上传、扫描、下载、对账）、决定 D53（标准物理访问走 SDK 的存储端口，不加纯转发组件）。本章写 SDK 的**存储端口**给属主组件的操作与它们的语义——三种语言的适配器提供同样的语义；附件的记录、凭证与状态由附件组件（`infra/attachment`）定义，不在本章。事件的大载荷（P6.14）与冷热转层（第 15 章）的对象存储访问以后并到这个端口。

本章的“属主”是拥有这些对象的组件；它只经自己的桶与前缀（`OBJECT_STORE_BUCKET`、`OBJECT_STORE_PREFIX`，第 02 章）访问，凭据只能访问它们。

## 键与对象

| 编号 | 层级 | 规则 | 检验 |
| --- | --- | --- | --- |
| P19.1 | 必须 | 端口的键是相对属主前缀的路径（`a/b/c`：段由小写字母、数字、`-`、`_`、`.` 组成，不以 `/` 开头，没有空段与 `..`）；端口在前面加上属主的前缀。键不放个人信息与原文件名（协议 12：键会进日志与地址） | SDK 测试 |
| P19.2 | 必须 | 对象的元数据：大小、内容类型、写入时刻；端口自己放入的对象另有内容的 SHA-256（放入时算出、作为元数据保存）。经预签名地址上传的、复制来的对象没有可信的摘要：要摘要的调用方读内容自己算，不信元数据 | SDK 测试 |

## 操作

| 编号 | 层级 | 规则 | 检验 |
| --- | --- | --- | --- |
| P19.3 | 必须 | **放入**（键、内容、内容类型；可选“只在不存在时”）：只在不存在时，键已存在答 `exists`，什么也不改。端口在第一次使用时探测存储是否遵守“只在不存在时”；不遵守的存储，端口拒绝一切条件写入（答 `unavailable` 并告警），绝不退成无条件写 | SDK 集成测试（对实际的存储） |
| P19.4 | 必须 | **复制**（源键、目标键、只在目标不存在时）：在存储一侧复制，目标的元数据由端口重写（不沿用源对象上客户端带来的元数据）；目标已存在答 `exists`。存储不支持带条件的服务端复制时，端口退回“读源、带条件放入目标”，语义相同（目标的内容就是复制那一刻读到的源内容）；用了哪一种在启动时探测并记日志 | SDK 集成测试 |
| P19.5 | 必须 | **读取**（键）：内容以流交出，同时给出元数据；**元数据**（键）只答元数据；不存在答 `not_found`（不同于存储不可达的 `unavailable`） | SDK 集成测试 |
| P19.6 | 必须 | **预签名上传**（键、确切的长度、内容类型、有效期）：答一个只能对这个键、以这个长度与类型 `PUT` 的地址；长度与类型签进签名（客户端改了即被存储拒绝）。有效期不超过 1 小时。预签名的地址用**浏览器可达的地址**（`OBJECT_STORE_PUBLIC_URL`，第 02 章；没配时用 `OBJECT_STORE_URL`）签名，组件自己的请求仍走 `OBJECT_STORE_URL`（P6.14 要求同一个项目网络内的主机名）；浏览器直传要的跨源规则由装配时的初始化给桶设上 | SDK 集成测试 |
| P19.7 | 必须 | **预签名下载**（键、有效期、下载的文件名、是否在浏览器内显示）：答一个只能 `GET` 这个键的地址；不在浏览器内显示时，响应头强制作为附件保存（`Content-Disposition: attachment`，文件名按 RFC 6266 编码），在浏览器内显示时类型由调用方从白名单里给。有效期不超过 1 小时；同样用浏览器可达的地址签名 | SDK 集成测试 |
| P19.8 | 必须 | **删除**（键）：不存在也算成功；**列举**（键前缀、游标）：按键排序分页 | SDK 集成测试 |
| P19.9 | 必须 | **错误的分类**：`not_found`、`exists`（条件不满足）、`too_large`、`unavailable`（不可达、超时、5xx：可重试）、`denied`（凭据或策略拒绝：不重试，告警）；存储的原始错误只进日志，签名与凭据脱敏 | SDK 测试 |
| P19.10 | 必须 | 端口不把预签名地址写进日志（地址里有签名与下载的文件名）；存储的原始答复写进日志时签名脱敏；端口不记录内容 | SDK 测试 |

## 不在本版

分段上传（协议 12 的 16 MiB 阈值；本版的单次上传上限是存储的单次 `PUT` 上限）、对象锁、版本保留的读取、跨属主的“拒绝”检查（由存储一致性套件证明，协议 12）只留形状。
